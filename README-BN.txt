====================================================================
TendaF3SpeedMeter — সেটআপ, পারমিশন এবং ব্যবহার নির্দেশিকা (বাংলা)
====================================================================

১. অ্যাপ সম্পর্কে
----------------
TendaF3SpeedMeter একটি হালকা (lightweight) এবং ব্যাটারি-সাশ্রয়ী Android
অ্যাপ, যা আপনার ফোনের স্ক্রিনের ওপর ভাসমান (Floating Overlay) হিসেবে রিয়েল-টাইম
ডাউনলোড (↓) ও আপলোড (↑) ইন্টারনেট স্পিড প্রদর্শন করে। পাশাপাশি Wi-Fi নেটওয়ার্কে
সংযুক্ত থাকলে এটি Tenda F3 রাউটার গেটওয়ের (ডিফল্ট: 192.168.0.1) পিং/ল্যাটেন্সি ও
রাউটার স্ট্যাটাস পর্যবেক্ষণ করতে পারে।


২. প্রজেক্ট ও Android Studio সেটআপ
-----------------------------------
ক) Android Studio-তে প্রজেক্টটি ওপেন করুন এবং Gradle Sync সম্পন্ন হতে দিন।
খ) ন্যূনতম SDK (minSdk): Android 7.0 (API 24) | Target SDK: API 36
গ) Kotlin ও Jetpack Compose ব্যবহার করা হয়েছে; আলাদা ভারী লাইব্রেরি ছাড়াই
   স্ট্যান্ডার্ড Android TrafficStats, ConnectivityManager ও WindowManager
   ব্যবহার করা হয়েছে।
ঘ) ডিভাইসে সরাসরি রান করতে USB Debugging চালু করে Run বাটনে ক্লিক করুন অথবা
   Build > Build Bundle(s) / APK(s) > Build APK(s) থেকে APK তৈরি করুন।


৩. প্রয়োজনীয় পারমিশন (Permissions) ও কারণ
-----------------------------------------
অ্যাপটি সঠিকভাবে চালানোর জন্য নিচের পারমিশনগুলো প্রয়োজন:

১) Display over other apps (SYSTEM_ALERT_WINDOW):
   - কেন প্রয়োজন: অন্যান্য অ্যাপের ওপর ভাসমান স্পিড মিটারটি দেখানোর জন্য।
   - কীভাবে দেবেন: অ্যাপের হোম স্ক্রিনে "Required Permissions" কার্ড থেকে
     "Grant" বাটনে ট্যাপ করুন > TendaF3SpeedMeter সিলেক্ট করে সুইচটি চালু করুন।

২) Notifications (POST_NOTIFICATIONS — Android 13+):
   - কেন প্রয়োজন: ব্যাকগ্রাউন্ড ফোরগ্রাউন্ড সার্ভিসটি চালু রাখা এবং নোটিফিকেশন
     বার থেকে সরাসরি "Stop" করার সুবিধা দেওয়ার জন্য।
   - কীভাবে দেবেন: "Grant" বাটনে ট্যাপ করে "Allow" নির্বাচন করুন।

৩) Network & Wi-Fi State (INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE):
   - এগুলো স্বয়ংক্রিয় ইনস্টল-টাইম পারমিশন; আলাদা করে অনুমতি দিতে হয় না।
   - লোকেশন (Location) পারমিশন ছাড়াই ডিভাইসের ট্রাফিক স্পিড ও গেটওয়ে আইপি
     পাওয়া যায়।


৪. ব্যবহার নির্দেশিকা (Usage Guide)
-----------------------------------
১) লাইভ ওভারলে চালু করা:
   - পারমিশনগুলো "Granted" হলে "Start Live Overlay" বাটনে ট্যাপ করুন।
   - স্ক্রিনের ওপর একটি ভাসমান স্পিড পিল (↓ Download / ↑ Upload) দেখা যাবে।

২) ওভারলে পজিশন পরিবর্তন ও টাচ:
   - স্পিড পিলটি আঙুল দিয়ে চেপে ধরে (Drag) স্ক্রিনের যেকোনো স্থানে সরানো যায়
     এবং অ্যাপ আপনার পছন্দের অবস্থান সংরক্ষণ করে রাখে।
   - পিলের বাইরের স্ক্রিনে টাচ করলে অন্যান্য অ্যাপ ব্যবহারে কোনো বাধা হবে না।
   - পিলে একবার ট্যাপ করলে দ্রুত অ্যাপের কন্ট্রোল স্ক্রিন ওপেন হবে।
   - অবস্থান রিসেট করতে চাইলে অ্যাপের "Reset Position" বাটনে ট্যাপ করুন।

৩) কাস্টমাইজেশন (Overlay Appearance & Sampling):
   - Speed Unit: KB/s · MB/s অথবা Kbps · Mbps বেছে নিন।
   - Refresh Interval: 1.0s (তাৎক্ষণিক), 2.0s (ব্যালেন্সড) বা 3.0s (ইকো)।
   - Pill Size ও Layout: Compact / Standard / Large এবং Stacked (২ লাইন)
     অথবা Inline (১ লাইন)।
   - Opacity Slider: স্বচ্ছতা ৪০% থেকে ১০০% পর্যন্ত নিয়ন্ত্রণ করা যায়।
   - Show Gateway Ping: পিলের সাথে গেটওয়ে পিং (ms) দেখাতে অন করুন।

৪) Tenda F3 রাউটার মনিটর:
   - Tenda F3 ওয়াই-ফাই রাউটারের সাথে সংযুক্ত থাকলে গেটওয়ে IP সাধারণত
     192.168.0.1 হয়। "Auto-detect" বাটনে চাপলে সংযুক্ত গেটওয়ে আইপি স্বয়ংক্রিয়ভাবে
     বসে যাবে।
   - রাউটার অ্যাডমিন পাসওয়ার্ড দেওয়া থাকলে ঐচ্ছিক পাসওয়ার্ড ঘরে লিখে
     "Test Gateway" বাটনে ট্যাপ করে সংযোগ ও পিং যাচাই করুন।

৫) সার্ভিস বন্ধ করা:
   - অ্যাপের ভেতরে "Stop Overlay" বাটনে ট্যাপ করুন, অথবা নোটিফিকেশন বারের
     "Stop" বাটনে ট্যাপ করুন।


৫. ব্যাটারি সাশ্রয় ও সুরক্ষা
----------------------------
- ফোনের স্ক্রিন বন্ধ (Screen Off) হলে সার্ভিসটি স্বয়ংক্রিয়ভাবে স্পিড পোলিং
  স্থগিত (Pause) করে দেয়, ফলে ব্যাটারি খরচ প্রায় শূন্য থাকে। স্ক্রিন অন করলে
  আবার স্বয়ংক্রিয়ভাবে চালু হয়।
- যদি কোনো কারণে সিস্টেম সেটিংস থেকে Overlay পারমিশন বন্ধ করে দেওয়া হয়,
  অ্যাপটি ক্র্যাশ না করে নিরাপদে ওভারলে বন্ধ করে সার্ভিস থামিয়ে দেয়।


৬. সমস্যা সমাধান (Troubleshooting)
----------------------------------
- ওভারলে দেখা না গেলে: নিশ্চিত করুন "Display over other apps" পারমিশন চালু
  আছে এবং ফোনের ব্যাটারি সেভার / অটো-স্টার্ট রেস্ট্রিকশন (Xiaomi/Oppo/Vivo/Realme)
  অ্যাপটিকে বন্ধ করছে না।
- স্পিড 0 B/s দেখালে: কোনো পেজ লোড বা ডাউনলোড না হলে ০ দেখানো স্বাভাবিক;
  বড় রিফ্রেশের জন্য 1.0s ইন্টারভ্যাল সিলেক্ট করুন।
- গেটওয়ে Unreachable দেখালে: ফোনটি রাউটারের Wi-Fi নেটওয়ার্কে যুক্ত আছে কি না
  এবং রাউটারের IP (যেমন 192.168.0.1 বা 192.168.1.1) সঠিক কি না যাচাই করুন।
